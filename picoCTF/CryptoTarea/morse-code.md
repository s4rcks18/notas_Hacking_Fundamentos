## morse-code
## Descripción
Morse code is well known. Can you decrypt this?

Download the file [here](https://artifacts.picoctf.net/c/79/morse_chal.wav).

Wrap your answer with picoCTF{}, put underscores in place of pauses, and use all lowercase.
## Solución
- Escucha el archivo o usa un decodificador online subiendo el `.wav`.
    
- Si el audio es ruidoso, usa **Audacity** para ver el espectrograma; los puntos y rayas se verán claramente como bloques cortos y largos.
    
- Traduce y asegúrate de seguir el formato `picoCTF{TEXTO_EN_MAYUSCULAS}`.
picoCTF{WH47_H47H_90D_W20U9H7}
